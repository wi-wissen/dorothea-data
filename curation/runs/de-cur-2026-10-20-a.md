## Instruction (verbatim)

# Run de-cur-2026-10-20-a: learner-ready German entries (instruction version 2)

You curate German dictionary entries for **Dorothea**, a reading aid for learners and school
students (German as a first, second or foreign language; English speakers reading German). The
sources are English and German Wiktionary (CC BY-SA). A reader taps a German word in a text and sees
a small card: it must show the senses a reader is likely to need, a short explanation in simple
German, and correct English translations. Work from your own knowledge of German and English. Do not
consult other dictionaries or word lists, and do not open any files other than the ones named below.

## Input

`/home/user/dorothea-build/cur-de1/batch-NN.jsonl`, one entry per line: `key, lemma, pos, gender,
rank` (frequency rank, lower = more frequent) and `senses`: `id`, `en` (English glosses currently
attached), `def` (English definition), `de_def` (German definition from German Wiktionary, if any),
`tags`, `src` (`enwikt` = English Wiktionary, `dewikt` = German Wiktionary). Senses from the two
sources often describe the same meaning twice.

## For every sense decide

1. **`show`**:
   - `main`: a sense a typical reader of everyday, school, news or fiction texts meets — including
     frequent colloquial or spoken uses. Card limit per **lemma** (all parts of speech together): 6,
     up to 8 for very versatile words (e.g. machen, gehen, haben, Zug).
   - `more`: correct and occasionally useful, but secondary. Shown under "Weitere Bedeutungen".
   - `hide`: obsolete, regional-only, very rare, narrow technical senses, pure cross-references, or a
     **duplicate** of another sense of the same entry (typical when both Wiktionaries describe the
     same meaning: keep the better one, hide the other, and move good translations over via `en_add`).
2. **`order`**: 1, 2, 3 … over `main` senses first, then `more` senses; most common first.
3. **`learner_de`** (for `main` and `more`): a short explanation in simple German: ≤ 12 words,
   vocabulary of level A2–B1 where possible, no circular use of the headword, written by you (do not
   copy the Wiktionary wording). For function words, describe the use ("verbindet zwei Sätze, wenn …").
4. **English** (for `main` and `more`):
   - `en_keep`: given English glosses that are correct translations for this sense.
   - `en_drop`: only glosses that are **wrong or misleading** for this sense — not correct second
     choices.
   - `en_add`: 1–3 common English translations if the sense has none correct, or a clearly better
     everyday one is missing. Base forms: verbs as `to …`, nouns without article.
5. **`missing`** (entry level, optional): a common meaning of the word that no sense covers, as a
   short German explanation plus English translation, e.g. `{"learner_de": "…", "en": ["…"]}`.
6. **`see`** (entry level, optional): if all senses are only cross-references or inflected forms, the
   base word they point to.
7. **`note`** (optional, ≤ 10 words).

## Output

`/home/user/dorothea-build/cur-de1/out-NN.jsonl`, one line per input entry, same order:

```json
{"key": "de:Zug:noun:1", "senses": [{"id": "…", "show": "main", "order": 1, "learner_de": "Fahrzeug auf Schienen mit mehreren Wagen", "en_keep": ["train"], "en_drop": [], "en_add": []}, {"id": "…", "show": "hide"}], "missing": null, "see": null}
```

Every input sense must appear exactly once with its `id`. Valid JSON per line. Verify with a short
script before finishing: same keys and sense ids in the same order as the input, allowed values only,
card limit per lemma, `order` puts all `main` before `more`, `learner_de` ≤ 12 words.

## Agent task line (verbatim; NN = the agent's batches)

## Post-processing

One agent wrote senses in curated order instead of input order (batches 05–09); the files were
re-sorted to input order by sense id (no content change). Two source entries have duplicate sense ids;
they were matched by position.

Patterns: a sense hidden as a "duplicate" although the two sources meant different things; long
gloss strings kept instead of replaced, sometimes with a wrong item inside; explanation and glosses
occasionally describe different senses; some explanations use idioms wrongly, words above B1, or the
headword itself; frequency calls are inconsistent (frequent news words or spoken uses under "more").

## Changes for the next run (instruction version 3)

- Hide a sense as a duplicate only if both describe the same meaning; move its correct translations.
- Replace multi-translation gloss strings by single clean glosses; never keep a string with a wrong item.
- The explanation must describe the same sense as the kept glosses.
- No headword (or compound of it) in the explanation; no idioms; A2–B1 words only.
- Frequent spoken uses and frequent news words belong on the card.
