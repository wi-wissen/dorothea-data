## Method

1. **Sample check.** 150 entries drawn at random from the 1,301 (Python `random.seed(29)`,
   `random.sample`). For each entry the German and English card was rebuilt as a reader sees it:
   shown senses in order with kept and added translations, `learner_fr`, `missing`. Every entry was
   judged by hand against five error classes.
2. **Decision.** The sample error rate was above 15 %, so all 1,301 entries were read and repaired,
   not only the sample.
3. **Repair.** All entries were read as rebuilt cards with the hidden senses and their source
   translations listed below each card. Every decision was written by hand as a short edit
   (show, order, explanation, keep/drop/add, missing); a script only applied the edits to the
   earlier decision, wrote the full records and validated them.

### How the output relates to the earlier run

The build applies runs in run-id order on top of each other. For translations this means that a
string the earlier run *added* stays unless the new record drops it. Where an earlier addition was
wrong (an English string in the German list, a German noun in a wrong form, a packed string), this
run lists it in `de_drop`/`en_drop`; the validator therefore allows a drop string that is either a
source gloss of the sense or an earlier run's `*_add` string for that sense (22 such drops).
Restoring a correct source string that the earlier run had dropped works through `*_keep` (the
build adds a kept string the sense no longer has).

8. *traduire*: German list contained "ea: to translate", English list empty → German
   "übersetzen", English "to translate" (same fix for "to express", "to bring to court").

12. *précis*: `missing` explanation contained the headword ("à huit heures précises") → rewritten

14. *lutte*: "wrestling" first, the "struggle" sense had no German → "struggle / der Kampf" first.
15. *chien*: gun part shown with English "hammer (of a firearm)" and no German → "hammer / der Hahn".

## Known gaps

- **Corrected `missing` items do not reach the build yet.** The build gives an entry's missing
  items the ids `cur-missing-<n>`, `-2`, … and adds an item only if the id does not exist yet, so a
  later run can append items but cannot replace or remove an earlier run's item. In 31 entries this
  run rewrites an existing missing item (headword in the explanation, German noun without article)
  or removes one (*mineur*, noun: duplicate of the adjective sense); these records hold the
  corrected lists, but the cards keep the earlier text until the build lets a later run's list
  replace the earlier one, or the corrections are copied into fr-cur-2026-10-24-a. Affected:
  arrêt, bis (adv.), capital (adj.), complémentaire (noun), congé, convenir, court (adj.),
  distinguer, domicile, habitude, hôtel, inspirer, intervention, introduire, italien (noun),
  lumière, mineur (noun 1), orientation, parti (adj.), passe (noun 1), prestation, profit, précis
  (adj.), revanche, russe (noun 1), révéler, salon, sorte, soumis (adj.), surface, équipement.
- Duplicates the build removes by itself ("affect" next to "to affect") were left alone.
- Technical or rare senses shown as `more` were not systematically demoted further; the check
  looked at what a reader sees first.
